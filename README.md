## 使用

- 安装依赖：`pip install -r requirements.txt`（需要 Python 3.10+ 与 PyQt6）
- 运行 `python main.py`，在控制器里设置「最多同时播放」，点击「开始轰炸」
- 也可以下载 Release 中打包好的 exe，双击运行按照提示操作即可

### 静默启动（不显示控制器窗口）

- 直接双击 [静默轰炸.cmd](静默轰炸.cmd)：一次弹出 8 个视频窗口，每个视频最长播放 30 秒，弹窗还会在屏幕上乱飞，全程不显示控制器窗口
- 等价的手动命令：`python main.py --silent --count 8 --duration 30 --fly`（视频目录也能改：`--assets D:\我的视频`）
- 弹窗数量、播放时长、视频目录、是否乱飞都写在 cmd 文件开头的几个变量里，直接改就行
- 静默启动后任务栏托盘里会有炸弹图标：**双击打开控制器**，右键菜单可以「开始/停止轰炸」「显示控制器」「退出」
- 命令行参数：

| 参数 | 说明 |
| --- | --- |
| `-s` / `--silent` | 静默启动：隐藏控制器窗口并立即开始轰炸，靠托盘图标退出 |
| `-n` / `--count` | 最多同时播放的弹窗数量，1 ~ 20，默认 3（超出范围会自动夹到边界） |
| `-d` / `--duration` | 单个视频最长播放秒数，0 ~ 300，0 表示不限制，默认 30 |
| `-f` / `--fly` | 弹窗乱飞，等价于勾上控制器里的「弹窗乱飞」，默认关闭 |
| `-a` / `--assets` | 视频所在目录，默认是程序同级的 `assets_light`；相对路径按当前工作目录算 |

- `静默轰炸.cmd` 会优先用同目录下的打包版 exe，其次用 pythonw（不会多出一个黑色控制台窗口），再退回 python
- 想中途结束请用托盘菜单的「退出」，它会像关控制器窗口一样逐个释放解码器

> ⚠️ 弹窗数量太高可能导致死机！每个弹窗都是一路独立的解码 + 播放，数量建议控制在个位数。

## 打包成 exe（可选）

- 双击 [打包exe.cmd](打包exe.cmd)：先检查并自动安装缺少的 PyQt6 / PyInstaller（需要联网），然后调用 PyInstaller 打包，产物在 `dist` 文件夹里
- 脚本开头的几个变量可以改：`ONEFILE`（1 = 单个 exe，方便分享；0 = 一个文件夹，启动更快）、`OPEN_DIST`（打包完自动打开 dist）、`COPY_HERE`（打包完把 exe 复制回项目根目录）
- exe 不自带视频：把 `assets_light`（或 `assets`）和它放在同一层文件夹里即可；视频在别处就用 `BrainrotBombing.exe --assets D:\我的视频`
- 打包版同样是窗口程序，没有控制台窗口，命令行参数和 `python main.py` 完全一致，例如 `BrainrotBombing.exe --silent --count 8 --duration 30 --fly`
- 想配合 [静默轰炸.cmd](静默轰炸.cmd) 使用，把 exe 放到项目根目录（或把脚本里的 `COPY_HERE` 改成 1），cmd 会优先使用同目录的 exe

## 视频压缩（可选）

仓库里的 `assets` 是原视频合集（约 550 MB）。想要更轻量的版本可以跑压缩脚本：

- 需要系统已安装 `ffmpeg`（没在 PATH 里就用 `--ffmpeg` 指定路径）
- 运行 `python compress_assets.py`，会把 `assets` 里的视频统一压到 360P（横屏按高度、竖屏按宽度缩放，不放大原视频）、单个最长保留 5 分钟，输出到 `assets_light`
- 常用参数：`--jobs` 并行数、`--crf` 画质（越大越小越糊）、`--overwrite` 重新压缩、`--dry-run` 只看命令，其余见 `python compress_assets.py --help`
- 想让程序播放压缩后的视频，把 `assets_light` 改名为 `assets` 即可（原 `assets` 需要先移走）；不想改名就用 `--assets` 直接指定目录，比如 `python main.py --assets assets`，或改 [静默轰炸.cmd](静默轰炸.cmd) 里的 `ASSETS_DIR`

## 玩法说明

- 每个弹窗随机播放视频目录（默认 `assets_light`，可用 `--assets` 改）里的一个视频，弹窗标题就是该视频的标题
- 弹窗比例与所播视频一致，大小不超过半个屏幕，位置随机且一定完整落在屏幕内
- 可勾选「弹窗乱飞」，让弹窗一边播放一边在屏幕上乱撞（碰到边缘会反弹，不会飞出屏幕）
- 滑条可设置单个视频的最长播放时长（0 ~ 5 分钟，默认 30 秒；拖到 0 表示不限制），长视频到点自动关窗
- 视频播放完毕弹窗自动关闭；关闭后程序会自动补上新弹窗，始终维持设置的数量
- 播放中的弹窗不会重复播放同一个视频；按 `Esc` 也能关闭弹窗
- 挑选视频时会优先选本次运行中播放次数最少的那些（每次都在其中随机挑），所以一轮之内不会重复，整体分布也很均匀
